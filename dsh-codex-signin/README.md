# Codex 登录 · dsh-codex-signin

在 DeepSeek Harness 自带的模型目录里配置 ChatGPT 账号可用的 Codex 模型，在聊天输入框切换模型和思考强度。本版本在 macOS 桌面版 0.2.2-rc.5 的随附运行时上验证。

## 安装与使用

1. 在「插件」中安装此包，或用新版安装包更新旧版。若桌面端提示重启，请先重启。
2. 打开「设置 → 模型 → openai-codex」。如果没有这一行，通过「添加模型提供商」选择它。首次点击「登录 ChatGPT」完成授权，之前用本机脚本保存的授权可以直接使用。
3. 点「编辑」，展开「自定义设置 → 模型目录」，点击「获取可用模型」。勾选想使用的多个模型并应用到列表。选中的新行带有账号报告的上下文窗口，保留的行沿用之前的设置。
4. 展开某个模型右侧的箭头，可以手动编辑「上下文窗口」。点编辑器底部的「保存」，所有选中的模型一起生效。关闭编辑器或取消选择弹窗，遵循 Harness 原有的草稿行为。
5. 在展开的模型行中选择「默认思考等级」。每个模型按 ID 独立保存，只列出该模型支持的档位。这个下拉框会立即保存；容量、名称和模型列表仍由底部「保存」按钮提交。选择「跟随提供方」可以清除该模型的指定档位。
6. 打开聊天输入框的模型菜单，在 OpenAI Codex 下切换已保存的模型。思考强度按当前模型与 Harness 共同支持的档位显示；切换到模型时会带入它的默认档位。在聊天中手动选择其他档位后，该会话使用手动选择。保存模型目录不更改其他会话的默认选择。

## 实现与开发

登录窗口复用 Host 的授权服务，凭据位于 Harness 的 `llm-pi-ai/openai-codex` 记录。账号列表来自 ChatGPT 的 `/backend-api/codex/models`。本机启用自定义 API 地址、协议或密钥的路由继续使用原有发现逻辑。

rc.5 的模型发现按设置命名空间注册，每个命名空间只有一个处理器。插件在本 Host 实例上装饰 `llm.discoverModels`，限定为原生 Codex 路由。原生候选格式携带容量和输入类型；保存时，插件把账号的思考档位补到缺少该字段的模型行。多选、模型顺序、容量编辑、版本冲突检查和聊天菜单均由 Harness 处理。默认档位保存在当前 profile 的插件配置 `dsh-codex-signin.config.modelDefaults`，按模型 ID 查找。rc.5 没有模型行扩展位，客户端只在 Codex 提供方已展开的行内挂载下拉框。Host 在该实例的模型元数据归一化步骤提供 `defaultEffort`，原生聊天菜单、请求准备和发送共用这一元数据。卸载会释放这些兼容处理；宿主升级后应重新验证原生多选和会话模型切换。

使用 Node.js 22.19 或更高版本，执行 `npm ci` 后运行 `node --test`。运行 `npm pack` 生成可安装的 tgz。
