# Fixup Patches

DeepSeek Harness 的个人补丁集合，不限于提示词。每条补丁默认开启，按 profile 独立管理。

在 DSH 侧栏选择「插件」→「添加插件」→「安装第三方插件」，输入本项目的绝对路径并启用组合包。安装后，从「插件」→「Fixup Patches」进入详情页，用各补丁的开关单独启停。

首条补丁「复用已加载的技能」只追加系统提示词：技能正文仍可见时复用，正文不在上下文时可以重载。它不会拦截工具调用，也不能保证模型不再重复加载。

新增补丁时，把实现放在 `patches/` 下，声明对应的包导出，再在 `cordis.patch.yml` 加一条独立插件项。保留已有插件 ID，以便 profile 继续识别已保存的开关。
